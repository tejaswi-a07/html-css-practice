This project is a frontend website for a modern chair store.

It includes:

- 🪑 Hero section with a chair introduction
- ⭐ Features section
- 💬 Customer review section
- 🛍️ Bestselling chairs section
- 🏷️ Sale badge and product ratings
- 💰 Product pricing
- 🛒 Add to Cart buttons
- 🤖 Simple chatbot interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
